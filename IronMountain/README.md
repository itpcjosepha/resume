# Iron Mountain Entertainment Services
Software Engineer / FileMaker Developer  
Hollywood, California | 2015

## Business Overview

Iron Mountain Entertainment Services provides media preservation, archival, storage, and digital transformation services for organizations managing large-scale physical and digital media assets.

This engagement supported a major archival and data migration initiative involving the processing, tracking, validation, and digital conversion of millions of backup tapes containing business-critical data.

The objective was to improve operational visibility, automate workflows, ensure data integrity, and provide reliable tracking throughout the tape ingestion and extraction lifecycle.

---

## Project Summary

Designed, developed, and enhanced a FileMaker-based application responsible for managing tape processing workflows, metadata tracking, job validation, reporting, and operational oversight.

The solution served as a centralized platform for tracking physical media assets from intake through extraction, validation, and digital delivery while supporting operational staff, project managers, and business stakeholders.

---

## Key Contributions

### Tape Processing & Workflow Management

- Developed and enhanced a FileMaker application used to manage large-scale tape ingestion and extraction operations.
- Automated workflow processes for tracking incoming media, validating tape jobs, and monitoring project status.
- Improved visibility into operational workloads and processing activities.

### Metadata & Asset Tracking

- Designed modules supporting the management of:
  - Media Assets
  - Projects
  - Accounts
  - Metadata
  - Tape Formats
  - Transport Information
  - Notes and Activity History
  - Milestones and Project Tracking
  - Billing and Invoicing

- Helped ensure data accuracy and traceability throughout the media conversion lifecycle.

### Reporting & Operational Visibility

- Designed and developed reporting tools that enabled stakeholders to:
  - Monitor project progress
  - Track processing milestones
  - Validate completed work
  - Generate operational and customer-facing reports

### Systems Integration

- Developed integrations utilizing:
  - FileMaker Pro
  - JavaScript
  - HTML
  - CSS
  - Microsoft SQL Server

- Implemented solutions allowing FileMaker Server hosted on macOS to communicate with Unix-based systems and supporting infrastructure.

### Platform Administration & Support

- Managed FileMaker Server deployments across both Windows and macOS environments.
- Provided database administration, application maintenance, troubleshooting, and ongoing platform support.
- Delivered end-user training and documentation to support operational teams.

### Legacy System Modernization

- Reverse engineered and analyzed legacy code developed by previous team members.
- Resolved defects, improved maintainability, and optimized application performance.
- Refactored critical functionality to improve reliability and processing efficiency.
