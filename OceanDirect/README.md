# Ocean Direct (2010-2015)
https://www.profoodsolutions.com/our-companies/richmond-wholesale

This project was created to sell a program that can orchestrate FileMaker migrations and updgrades using the FileMaker Comman Line tools in a modern web-based format.

These screenshots are from un-released software called "ProMigrator 2FM". 

    Technology Stack:
        • Node22 
        • Express 
        • JS/HTML 
        • CSS3 
        • SQLlite3 
        • Postgres
        • ThreeJS animation
        • React (20-30%) 

The program essentially replaces a command line tool with a web based service that can perform the CLI commands. It’s completely metadata driven, the information is driven from a SQLlite3 Database. And the paid tier includes connections to FileMaker Server, orchestrated data migrations and updates. The program was designed with a licensing server that handles the annual registration for paid tiers using Postgres.
