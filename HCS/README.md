## Business Overview

Hearing Care Solutions is part of WS Audiology (WSA), one of the world's largest manufacturers of hearing aids and hearing healthcare solutions.

Operating globally across numerous markets, WSA supports hearing healthcare providers, patients, and business operations through a combination of technology platforms, healthcare services, and data-driven decision-making.

This engagement focused on modernizing reporting capabilities and improving access to operational data stored within a legacy FileMaker-based business application.

---

## Project Summary

Designed and implemented a large-scale data integration and reporting solution that extracted, transformed, and loaded data from an 8-year-old FileMaker application into Microsoft SQL Server.

The objective was to eliminate reporting bottlenecks, improve data accessibility, support enterprise analytics initiatives, and enable modern reporting platforms such as Power BI and Sisense.

The solution processed more than 7 million records daily, providing business teams with timely access to operational and reporting data without impacting production application performance.

---

## Business Challenge

The organization relied heavily on a mature FileMaker solution that had evolved over many years.

While the platform successfully supported business operations, reporting workloads against the production environment could require significant processing time and impact system performance.

Business stakeholders needed:

- Faster reporting capabilities
- Improved data accessibility
- Enterprise-grade analytics support
- Reduced impact on production systems
- Improved scalability for future reporting initiatives

---

## Key Contributions

### Enterprise ETL Architecture

- Designed and developed a custom ETL solution responsible for extracting, transforming, and loading data from FileMaker backups into Microsoft SQL Server.
- Automated daily processing of more than 7 million rows of business data.
- Created repeatable workflows for data extraction, validation, transformation, and loading.

### Legacy System Reverse Engineering

- Reverse engineered an 8-year-old production FileMaker application to understand business logic, data structures, and relationships.
- Created a new FileMaker-based analysis and extraction framework specifically designed to support reporting and data migration requirements.
- Developed a scalable approach for translating legacy application structures into relational SQL Server models.

### Data Warehouse & Reporting Enablement

- Delivered SQL Server-based reporting datasets optimized for analytics workloads.
- Enabled business users and reporting teams to leverage:
  - Power BI
  - Sisense
  - SQL-based reporting tools

- Reduced dependency on resource-intensive reporting directly against the production FileMaker environment.

### Systems Integration & Automation

Implemented automated integration workflows utilizing:

- FileMaker Server Admin API

- SQL Server Linked Servers
- Bulk Import Processes
- CSV Transformation Pipelines
- Batch Processing Frameworks

### Security & Compliance

### SDLC & Environment Management
