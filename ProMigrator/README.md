# Projects and Engagements
ProMigrator 2FM (today)
The screenshots are from new un-released commercial software called "ProMigrator 2FM". 

The entire solution is Node + Express +  JS/HTML + CSS3 + SQLlite3 + Postgres and about 20-30% of the program uses React. 

The program essentially replaces a command line tool (CLI) with a web based service that can perform the CLI commands. 

It’s completely metadata driven, which means the information is driven from a Database. 

Paid tier includes connections to FileMaker Server, orchestrated data migrations and updates. 

The program was designed with a licensing server that handles the annual registration for paid tiers.
