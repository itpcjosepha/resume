# Warner Bros. Discovery (2022-2024) 

Automated Warner Bro’s Discovery FileMaker solutions of 45+ files through DEV, UAT, and PROD environment across multiple servers across the United States. 

This FileMaker program was writtent to track and manage all of their FileMaker files with approximately 80+ users on East and West Coast servers.

The program I implemented was specifically written to allow a non technical person to promote a FileMaker file through their different environments. 

Included is a document to provide an example of my technical writing skills and documentation. This was a 2 year "term out" contract.

        • PowerShell
