# Screenshots Gallery

Store screenshots here for projects and contract engagements.

Suggested organization:

- One subfolder per project or client
- Clear filenames that describe the screen or workflow shown
- Prefer short markdown indexes in each subfolder for context

Examples:

- `project-name/dashboard-overview.png`
- `project-name/mobile-checkout-flow.png`
- `client-engagement/admin-reporting.png`
