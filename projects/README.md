# Projects and Engagements

This section is the main portfolio index for Joseph E. Arzate Jr.'s work history.

Use this folder to organize each project or contract engagement with:

- A short project summary
- Role and responsibilities
- Technologies used
- Links to screenshots in [`/artifacts/screenshots`](../artifacts/screenshots/README.md)
- Links to supporting documents in [`/artifacts/documents`](../artifacts/documents/README.md)

## Suggested Entry Format

For each project or engagement, capture:

| Field | Description |
| --- | --- |
| Project / Client | Name of the project, client, or engagement |
| Role | Title or primary contribution |
| Dates | Timeframe of the work |
| Summary | Brief description of the outcome or scope |
| Artifacts | Links to screenshots and documents |

Create one markdown file per project in this folder as the living resume grows.
